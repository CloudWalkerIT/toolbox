# scripts/

Repo-level helper scripts — bootstrap, maintenance, and other cross-cutting
chores for working on this repository itself.

What belongs here: tooling that operates on the repo, not on a customer's
cloud. These are distinct from the customer-facing tools in `cloud/`,
`diagnostics/`, and `reporting/`.

Keep scripts small and documented. A script that grows into a real tool
belongs in one of the category directories instead.
