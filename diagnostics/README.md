# diagnostics/

Health checks and troubleshooting tools.

What belongs here: tools that probe a running environment to answer "is this
healthy?" or "why is this broken?" — connectivity checks, configuration
drift detection, log triage, and similar.

Each tool is self-contained: its own directory, its own `README.md`, and its
own dependency manifest. See the repository [README](../README.md#adding-a-tool-polyglot-convention)
for the full convention.
