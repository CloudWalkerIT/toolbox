# reporting/

Tools for turning raw findings into customer-facing reports.

What belongs here: tools that take output from `cloud/` or `diagnostics/`
tools and shape it into something a customer reads — summaries, scored
findings, exportable documents.

Each tool is self-contained: its own directory, its own `README.md`, and its
own dependency manifest. See the repository [README](../README.md#adding-a-tool-polyglot-convention)
for the full convention.
